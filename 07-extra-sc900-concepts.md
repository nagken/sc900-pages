# Extra SC-900 Concepts

> Concepts that span multiple domains or appear inconsistently in the exam outline but show up on the test.

## Zero Trust pillars

Identity, Endpoints, Apps, Data, Infrastructure, Network. SC-900 emphasizes Identity and Endpoints. Each pillar gets policy enforcement, telemetry, and automation.

## Encryption at rest vs in transit

Azure Storage encrypts at rest by default with platform-managed keys; you can switch to customer-managed keys (CMK). In transit uses TLS 1.2+. End-to-end is encryption maintained inside the application.

## Microsoft Entra brand consolidation

Azure AD = Entra ID; Azure AD External Identities = Entra External ID; CloudKnox = Entra Permissions Management. Same products, new names.

## Trust Center vs Service Trust Portal

Trust Center = marketing front door; Service Trust Portal = the actual report downloads (audits, pentests).
