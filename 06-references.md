# SC-900 Concept and Reference Index

> Quick-lookup index of every term, service, and acronym you will see on the exam.

- **Microsoft Entra** - Umbrella brand for Microsoft identity and network access products
- **Defender XDR** - Cross-domain detection and response for M365
- **Defender for Cloud** - CSPM + workload protection for cloud and hybrid
- **Microsoft Sentinel** - Cloud-native SIEM and SOAR
- **Microsoft Purview** - Unified data governance and compliance
- **Conditional Access** - Policy engine that evaluates signals at sign-in
- **PIM** - Privileged Identity Management - JIT role activation
- **CASB** - Cloud Access Security Broker (Defender for Cloud Apps)
- **CSPM/CWP** - Posture management vs runtime workload protection
- **KQL** - Kusto Query Language for Sentinel and Log Analytics
- **SOC 2 / ISO 27001 / FedRAMP** - Common compliance frameworks shipped as Compliance Manager templates
