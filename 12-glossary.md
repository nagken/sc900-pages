# Glossary and Acronyms - SC-900

| Term | Definition |
|---|---|
| **AuthN / AuthZ** | Authentication = prove identity; Authorization = grant permissions |
| **MFA** | Multifactor authentication - 2+ factors from know/have/are |
| **FIDO2** | Phishing-resistant passwordless standard (security keys, WHfB) |
| **Conditional Access** | Entra policy engine: signals -> decision -> controls |
| **PIM** | Privileged Identity Management - JIT/time-bound role activation |
| **RBAC** | Role-based access control |
| **CASB** | Cloud Access Security Broker - Defender for Cloud Apps |
| **CSPM** | Cloud Security Posture Management |
| **EDR** | Endpoint Detection and Response |
| **SIEM** | Security Information and Event Management - Sentinel |
| **SOAR** | Security Orchestration, Automation and Response - Sentinel playbooks |
| **DLP** | Data Loss Prevention |
| **IRM** | Insider Risk Management |
| **eDiscovery** | Identifying/preserving/exporting electronic records for legal review |
| **Sensitivity label** | Protective tag on a document/email - controls encryption, marking, access |
